# Rahul Naidu journal

This is the source for my personal AI engineering journal at blog.neuromancer.in.

The site is built with Astro 6, vanilla CSS, and MDX content collections. Posts live in `src/content/blog`, with optional frontmatter fields for margin notes and post sidenotes.

The design language is a cyanotype journal: rag paper, prussian rules, Source Serif body text, Besley headings, and paper/print themes.

## Commands

```sh
npm install
npm run dev
npm run build
npm run preview
```

`npm run dev` starts the local Astro server. `npm run build` writes the production site to `dist`.
